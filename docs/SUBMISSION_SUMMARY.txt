================================================================================
SELECTED INEQUALITIES
================================================================================

1. CAUCHY-SCHWARZ INEQUALITY
   Statement: (∑aᵢbᵢ)² ≤ (∑aᵢ²)(∑bᵢ²)
   Difficulty: Medium
   Key Theorems: Quadratic discriminant, inner products
   Proof Method: Discriminant of non-negative quadratic

2. JENSEN'S INEQUALITY
   Statement: f(∑λᵢxᵢ) ≤ ∑λᵢf(xᵢ) for convex f
   Difficulty: High
   Key Theorems: Convexity definition, induction
   Proof Method: Mathematical induction on convex functions

================================================================================
KEY FINDINGS
================================================================================

1. ANSWER ≠ PROOF
   LLMs can find correct answers through pattern matching or heuristics,
   but constructing rigorous step-by-step proofs is significantly harder.

2. LOGICAL GAPS DOMINATE
   85% of proof failures involve missing reasoning steps or unjustified
   claims, making this the most critical error type.

3. PROMPT OPTIMIZATION WORKS
   Structured prompts with explicit requirements and error prevention
   examples significantly improve proof quality (20-50% improvement).

4. GRANULAR EVALUATION ESSENTIAL
   Single holistic judges perform poorly. Specialized judges for different
   error types provide more accurate and actionable evaluation.

5. SCALING LIMITATIONS
   Simply increasing model size or test-time compute doesn't solve proof
   correctness. Structured reasoning support is more effective.
